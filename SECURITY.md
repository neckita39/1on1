# Безопасность приложения 1-on-1

## ✅ Реализованные меры защиты

### 1. Сетевая безопасность
- ✅ **Порт закрыт для внешнего доступа**
  - Приложение доступно только на `127.0.0.1:3000`
  - Доступ возможен только с локального компьютера

### 2. Аутентификация
- ✅ **Минимальная длина пароля: 12 символов**
- ✅ **Безопасное хранение паролей**: bcrypt через `password_hash()`
- ✅ **JWT токены**: httpOnly cookie, срок жизни 7 дней
- ✅ **Криптографически стойкие секреты**: 64 символа (256 бит)

### 3. Защита от атак
- ✅ **Rate limiting через Redis**: максимум 5 попыток входа за 5 минут
- ✅ **Блокировка по IP** при превышении лимита
- ✅ **Персистентное хранение** попыток входа (переживает рестарт)
- ✅ **CSRF защита**: SameSite cookie policy

### 4. Резервное копирование
- ✅ **Скрипты backup/restore**
- ✅ **Автоматическая очистка** старых backup'ов (30 дней)
- ✅ **Сжатие backup'ов** (gzip)

## 📋 Рекомендации по использованию

### Регулярные backup'ы
```bash
# Вручную
./backup.sh

# Автоматически через cron (каждую ночь в 2:00)
crontab -e
# Добавить строку:
0 2 * * * cd /path/to/1on1 && ./backup.sh >> /var/log/1on1-backup.log 2>&1
```

### Восстановление из backup'а
```bash
./restore.sh
# Следуйте инструкциям на экране
```

### Доступ из локальной сети
Если нужен доступ не только с localhost, настройте reverse proxy:

**Вариант 1: nginx**
```nginx
server {
    listen 80;
    server_name 1on1.local;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

**Вариант 2: изменить docker-compose.yml**
```yaml
ports:
  - "192.168.1.100:3000:80"  # Замените на IP вашего сервера
```

## ⚠️ Дополнительные рекомендации

1. **Используйте сложные пароли**
   - Минимум 12 символов
   - Комбинация букв (верхний/нижний регистр), цифр и символов
   - Избегайте словарных слов

2. **Не используйте одинаковый пароль** для разных систем

3. **Регулярно создавайте backup'ы**
   - Настройте автоматические backup'ы через cron
   - Храните backup'ы в безопасном месте (отдельный диск, облако)

4. **Не делитесь паролем**
   - Каждый пользователь должен знать свой пароль
   - Не отправляйте пароль по электронной почте или мессенджерам

5. **Следите за обновлениями**
   - Регулярно обновляйте Docker образы
   - Следите за уязвимостями в зависимостях

## 🚨 Сброс пароля

### Если забыли пароль

**Вариант 1: Сброс пароля (данные сохраняются)**
```bash
docker exec 1on1-backend sqlite3 /app/var/data/app.db \
  "UPDATE settings SET password_hash = NULL WHERE id = 1"
# Затем откройте приложение и установите новый пароль
```

**Вариант 2: Полная пересоздание БД (ПОТЕРЯ ВСЕХ ДАННЫХ!)**
```bash
docker exec 1on1-backend php bin/init-db.php
```
